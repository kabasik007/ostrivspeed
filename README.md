# OstrivSpeed

OstrivSpeed — тренер для Windows, який керує **внутрішньою швидкістю симуляції Ostriv**. Календар, робота мешканців, будівництво й економіка просуваються швидше; застосунок не підміняє таймери Windows і не змінює EXE гри на диску.

Працює лише з перевіреною збіркою Ostriv **0.5.9.65 / Steam build 26211342**. Інші збірки відкриваються тільки для перегляду: запис у пам’ять заблокований. Для цієї версії [задокументовано адреси та шлях оновлення часу](research/RE_FINDINGS.md).

## Запуск

Потрібні Windows x64 і Rust. У корені репозиторію:

```powershell
cargo build --release
target\release\ostrivspeed.exe
```

При звичайному запуску відкривається одне вікно без консолі. Запустіть Ostriv, увімкніть «Дозволити керування для цієї сесії» та натисніть «Під'єднатися». Доступні звичайні пресети **1×, 5×, 12×, 15×, 20×, 30×, 50×**. Кнопка повернення й від’єднання встановлює 1×. Вікно показує задану, поточну й фактично виміряну швидкість ігрового часу.

## Гарячі клавіші

Натисніть на кнопку комбінації у блоці «Гарячі клавіші», а потім введіть нову. Підтримуються **F1–F24** без модифікаторів і літери, цифри, Up/Down з Ctrl, Alt або Shift. Наприклад: **F1**, **F2**, **Ctrl+Shift+F**. Esc скасовує призначення. Комбінації зберігаються в `%LOCALAPPDATA%\OstrivSpeed\hotkeys.txt` і працюють глобально лише після під’єднання до гри. Типові: Ctrl+Alt+0 для 1×, Ctrl+Alt+1…7 для пресетів, Ctrl+Alt+Up/Down для перемикання.

## Короткі проби 60×, 70× і 100×

У блоці «Короткий експеримент» окремо дозвольте пробу й виберіть швидкість. Програма утримує її **не довше двох секунд**, вимірює хід світу та процесорний час, після чого намагається повернути 1×. При зупинці ігрового часу вона скидає швидкість раніше. Ці значення відсутні серед звичайних пресетів і гарячих клавіш.

**60× уже зупиняло гру в попередньому вимірюванні. 70× і 100× ще не перевірялися в грі.** Використовуйте резервну копію збереження; короткий ліміт не гарантує стабільності рушія.

## Діагностика

Команди для термінала:

```powershell
target\release\ostrivspeed.exe --status
target\release\ostrivspeed.exe --hotkey-check
target\release\ostrivspeed.exe --restore
target\release\ostrivspeed.exe --experimental-speed 15 10
```

Остання команда виконує вимірювання на одному зі звичайних пресетів протягом 1–30 секунд. Якщо гра запущена з вищими правами, застосунок також потребує відповідного доступу до її процесу. Невідома версія EXE або несподіване значення в пам’яті блокує зміну швидкості.

[Результати вимірювань](docs/TEST_RESULTS.md) · [План дослідження](docs/REVERSE_ENGINEERING_PLAN.md)

Інтерфейс натхненний [OpenSpeedy](https://github.com/game1024/OpenSpeedy), але код і механіка керування власні. OpenSpeedy перехоплює системні часові функції; OstrivSpeed звертається тільки до перевіреної змінної швидкості самої гри. Бінарні файли Ostriv та сторонніх тренерів не входять до репозиторію.
